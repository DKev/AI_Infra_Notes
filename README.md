# AI_Infra_Notes

我用来记 **AI 基础设施** 学什么的：笔记和能复现的动手。训练、推理、数据/平台、硬件、可观测我都会碰，不锁死一个技术栈，**我主要想搞清问题是什么、工具有什么边界**。

## 我怎么看这个仓

| 目录 | 我打算怎么用 |
|------|----------------|
| [topics/](topics/) | 我按主题写：概念、对比、**用我自己话**复述 |
| [labs/](labs/) | 我放小实验、Notebook、脚本、能跑通的最小配置 |
| [resources/](resources/) | 我建索引：论文/文章/课程，**方便我以后搜、再打开** |
| [cheatsheets/](cheatsheets/) | 我**真会再查的**命令、工具、调参，随用随加 |
| [assets/](assets/) | 我画的图、截的图，笔记里会引用 |

## 我的学习地图（我想都碰、可以并行）

- **基础**：我先把单卡/单机训练、推理、简单 profiling 跑熟；**我用什么框架就记什么**
- **训练扩展**：多机多卡、怎么并行、通信、checkpoint/弹性、效率和显存
- **推理与在线服务**：批、延迟/吞吐、量化、各种 serving 栈**各自能干什么**（我不必先绑一个）
- **数据与 MLOps**：数据管线、实验怎么跟、从训练到部署怎么串
- **硬件与系统**：GPU/网/存、钱和利用率、容量
- **可观测与可靠性**：监控、SLO、怎么排障、变更和回滚

`topics/` 里编号只是**我大致推荐的顺序**，我可以按兴趣穿插；`labs/` 我可以和某块 topic 同步做。

## 我给自己定的笔记规矩

- 每个 `topics/*/` 里我尽量用 **一个入口**（比如 `README.md`）当目录
- 我写到哪，就链到 `labs/` 里具体路径、或者别的 topic，**别让一个文件巨长**
- 大文件、权重、密钥我不往仓里推；**我只写说明或脱敏名**

## 我手头还有什么

- 根目录的 `rc2rp-notebook.ipynb`：我有空会挪到 `labs/<我起的实验名>/`，然后在这里**补一行**链过去，和某个主题对上。
