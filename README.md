# AI_Infra_Notes

个人学习 **AI 基础设施** 的笔记与动手实验，训练、推理、数据/平台、硬件、可观测**都会碰**，不假设固定技术栈，以理解问题与工具边界为主。

## 本仓库怎么读

| 目录 | 内容 |
|------|------|
| [topics/](topics/) | 分主题笔记：概念、比较、自己的话总结 |
| [labs/](labs/) | 可复现小实验、Notebook、脚本、最小配置 |
| [resources/](resources/) | 论文/文章/课程索引，方便检索和二次打开 |
| [cheatsheets/](cheatsheets/) | 命令、工具、调参速查（随用随加） |
| [assets/](assets/) | 图、架构示意（随笔记引用） |

## 学习地图（都碰、可并行）

- **基础**：单卡/单机训练与推理、基本 profiling、框架习惯（你用什么框架就记什么）
- **训练扩展**：多机多卡、并行策略、通信、checkpoint/弹性、效率与显存
- **推理与在线服务**：批处理、延迟/吞吐、量化、典型 serving 栈的概念对比
- **数据与 MLOps**：数据管线、实验追踪、从训练到部署的一条线
- **硬件与系统**：GPU/网络/存储与成本、容量与利用率
- **可观测与可靠性**：监控、SLO、排障、容量与变更

`topics/` 下编号只表示**推荐大致顺序**，可按兴趣穿插；`labs/` 可和对应 topic 同步推进。

## 笔记约定（写给自己）

- 每个 `topics/*/` 里优先用 **一个入口文件**（如 `README.md`）做索引
- 笔记里链接到 `labs/` 路径、以及其它 topic，避免单文件过长
- 大文件与密钥不进仓库，用说明或脱敏指代

- 根目录 `rc2rp-notebook.ipynb`：可逐步挪到 `labs/<实验名>/` 并在此补一行链接，便于和主题对应。
